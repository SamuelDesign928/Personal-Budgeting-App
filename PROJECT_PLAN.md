# Project Plan (Complete)

This project was developed as a personal finance tracking application
using Python, Tkinter and SQLite.

## Features

### Database
- SQLite database
- Relational database structure
- Foreign keys
- CRUD operations
- Transaction handling
- Commit and rollback behaviour

### Models
- Dataclasses for categories, transactions and budgets

### Validation
- Amount validation
- Date validation
- Category name validation
- Budget period validation

### GUI
- Dashboard
- Category management
- Transaction management
- Budget management

### Financial Logic
- Total spending
- Spending by category
- Date filtering
- Budget usage
- Remaining budget
- Weekly, fortnightly and monthly budget periods

### Dashboard
- Total spending
- Current-month spending
- Transaction count
- Spending by category
- Budget progress
- Recent transactions

## Finalisation
- Testing
- Documentation
- Repository cleanup
- GitHub publication
