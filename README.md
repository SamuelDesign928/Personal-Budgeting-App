# Personal-Budgeting-App
A desktop personal finance tracker built with SQLite and Tkinter within Python. It features financial reporting, budgeting aid and transaction reports.

The project is being developed as a portfolio project with an emphasis on clean architecture, modular design and maintainable code.

Planned Features
  -> Transaction management
  -> Budget tracking
  -> Savings goals
  -> Dashboard
  -> Financial reports
  -> Data visualisation


## Current Status

Project planning and initial setup completed.
